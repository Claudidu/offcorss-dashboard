# Frontend · Offcorss Dashboard

React + TypeScript con Vite, estilos con Tachyons. Se publica en GitHub Pages.

```bash
npm install
npm run dev      # http://localhost:5173/offcorss-dashboard/
npm run build    # revisa tipos y compila en dist/
npm run deploy   # publica dist/ en la rama gh-pages
```

La documentación completa (arquitectura, decisiones, requisitos y despliegue) está en el [README principal](../README.md).
